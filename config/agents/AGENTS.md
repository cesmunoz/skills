# Agent rules

These rules apply in every repo and every tool.

- Answer in the user's language. Repo content follows the repo's language.
- Prove it works before calling it done. Run it, and show the output. A change that might help is a hypothesis.
- Never push to main. Work on a branch and open a pull request.
- Never print secrets. Read them from env vars. Do not paste tokens, keys, or passwords into code, logs, or chat.
- Prefer the smallest change that solves the problem.
- A reversible choice is made and reported. An irreversible one (force-push, deleting data, a message to a customer) asks first.
